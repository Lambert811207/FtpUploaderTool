# FtpUploaderTool

FtpUploaderTool 是一个 Windows FTP 自动上传工具。它监控本地目录，将符合规则且已稳定的文件上传到 FTP 服务器，并按任务配置处理上传成功后的本地文件。项目使用 C++、MFC 和 Visual Studio 2010 构建。

## 功能

- 最多配置 32 个任务，支持文件名通配符、排除规则和子目录扫描。
- 上传前检查文件稳定时间及写入占用；支持 PASV 和 PORT 模式、UTF-8 和 GBK 文件名。
- 支持临时文件名上传、服务器文件大小校验和上传完成后重命名。
- 可选择覆盖、改名或不上传同名文件；上传成功后可删除、备份或保留本地文件。
- 支持连接测试、断线重连、任务状态和 TXT 日志，以及可选的旧空目录清理。

当前支持普通 FTP，不支持 FTPS、SFTP 或断点续传。

## 环境与构建

- Windows；目标系统为 Win32 Windows XP SP3 及以上、x64 Windows XP Professional x64 及以上。XP 目标尚未完成实机验收。
- Visual Studio 2010 SP1，安装 C++、MFC 和 Windows SDK；使用 v100 工具集和 .NET Framework 4.0 MSBuild。

打开 [FtpUploaderTool.sln](FtpUploaderTool.sln)，选择 `Debug` 或 `Release` 以及 `Win32` 或 `x64` 后生成。也可以在项目根目录运行：

```bat
build.cmd Release
build.cmd Release x64
```

第一个命令构建 Win32，第二个构建 x64。输出分别位于 `Release\` 和 `x64\Release\`；Debug 输出位于对应的 `Debug` 目录。

## 快速开始

1. 启动生成的 `FtpUploaderTool.exe`，点击“新增任务”。
2. 填写服务器地址、端口、账号和密码，选择本地监控目录并填写服务器上传目录。
3. 按需要设置文件筛选、连接模式、同名文件策略和上传后的本地处理方式；使用“测试连接”检查服务器访问。
4. 保存任务、勾选任务并点击“全部启动”。任务列表显示状态与进度，日志区显示上传结果和错误。

新任务默认在上传成功后**删除本地文件**。如需保留原文件，请在启动前改为“保留”或设置备份目录。程序启动时会自动运行已勾选任务；关闭窗口或按 Esc 会隐藏到系统托盘，退出可通过托盘菜单操作。

## 数据和安全

程序按需在可执行文件目录下创建 `Config/`、`Data/`、`Log/` 和 `Dump/`，运行账户需要有相应的写入权限。配置和远程临时文件清理记录可能包含**明文 FTP 密码**；普通 FTP 的账号、密码和数据也不加密传输。请限制这些目录的访问权限，并在可信网络中使用。提交问题或分享日志前，请检查并移除密码、服务器地址、本地路径及其他敏感信息。

上传历史保存在 `Data/History_<任务 GUID>.txt`，以相对路径、大小和最后修改时间识别已上传文件，不计算内容哈希，也不会逐一确认服务器上的文件仍然存在。临时文件清理失败时会保留记录并在后台重试。
